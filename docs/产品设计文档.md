# 老年桌面（Elder Desktop）— 产品设计文档

> 版本：MVP v0.1　|　状态：设计草案　|　最后更新：2026-09-20

## 1. 产品概述

**一句话定位**：一款面向完全没接触过智能手机的长辈、安装后替换手机桌面的「大字 Launcher」，把打电话、看家人、看照片、紧急求助这些刚需收敛为「开机即用、点一下就完成」。

**要解决的问题**：传统手机桌面存在大量长辈看不懂的图标、弹窗、权限与二级菜单，学习成本过高。本产品用「零学习成本」的交互取代原生桌面，让长辈只面对几个大按钮。

**目标平台**：Android 手机（原生替换桌面的 Launcher 应用）。

## 2. 目标用户与核心场景

| 维度 | 说明 |
|---|---|
| 目标用户 | 从未接触过智能手机的长辈（60 岁以上） |
| 使用设备 | 子女提供的安卓手机，本产品设为默认桌面 |
| 核心场景 | ① 想看时间/天气 ② 想给子女打电话 ③ 想看家人照片 ④ 突发紧急情况求助 |
| 使用频率 | 高频日常使用，每次操作应「≤ 1 次点击」完成 |

## 3. 核心设计原则（体验底线）

这些是硬约束，任何功能都不得违反：

1. **一键直达**：所有操作控制在「点一下」以内，不设二级菜单。
2. **零学习成本**：无设置页、无账户、无权限弹窗；所有配置默认写死。
3. **看得清**：超大字体、超高对比度、大点击热区、防误触。
4. **稳定安全**：开机直达、响应快、无广告、不出错，禁止任何后台打扰。
5. **不依赖长辈操作**：联系人、紧急号码、相册内容由子女侧预置。

## 4. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 语言/UI | Kotlin + Jetpack Compose | 现代 Android 原生，声明式 UI |
| 应用类型 | Launcher（桌面替换） + 常规 App 双形态 | 设为默认桌面，亦提供普通入口 |
| 系统能力 | 电话/短信 API、Launcher 清单 | 支撑拨号与 SOS |
| 数据 | 本地存储（联系人/相册预置） | 无需服务器、无账号 |

## 5. MVP 范围（整体方向）

**第一屏（桌面首页）**：大时钟 + 日期 + 天气，四个大图标（电话 / 家人 / 照片 / SOS），仅一屏、无滑动。

**MVP 只做 4 个核心功能**：

| 模块 | 功能定义 | 交互 |
|---|---|---|
| 电话 | 拨号 + 家人通讯录 | 一个「拨号」大按钮 → 头像+名字列表 → 点按即拨；**不提供实体拨号盘** |
| 家人 | 照片+名字列表 | 点击直接拨打或视频 |
| 照片 | 家人相册浏览 | 全屏大图轮播，点 / 滑切换 |
| SOS | 紧急求助 | 点两下确认 → 拨打预设号码 + 短信通知家人 |

## 6. 非目标（MVP 明确不做）

以下功能一律留到 MVP 之后的迭代，避免拖长周期：

- 视频通话（暂不接入账号体系）
- 消息 / 微信类即时通讯
- 吃药提醒、健康监测
- 账户体系、云同步
- 设置页与个性化配置

## 7. MVP 验收标准

- 开机（设为默认桌面后）直接进入大字桌面，无需任何点击。
- 桌面仅一屏，四入口均可「点一下」进入对应功能并完成操作。
- SOS 在两次确认后成功触发拨号与短信，且不会误触。
- 全应用无二级菜单、无设置页、无广告、无权限弹窗。
- 在低端安卓机上流畅运行，响应无卡顿。

## 8. 后续迭代方向（MVP 验证后）

视频通话 → 吃药/日程提醒 → 子女远程协助设置 → 极简消息。每一步都以真实长辈的接受度数据为准，不盲目堆功能。
