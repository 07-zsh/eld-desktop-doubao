# 老年桌面（Elder Desktop）— 产品设计文档

> 版本：MVP v0.1　|　状态：设计草案　|　最后更新：2026-09-20

## 1. 产品概述

**一句话定位**：一款面向完全没接触过智能手机的长辈、安装后替换手机桌面的「大字 Launcher」，把打电话、看家人、看照片、紧急求助这些刚需收敛为「开机即用、点一下就完成」。

**要解决的问题**：传统手机桌面存在大量长辈看不懂的图标、弹窗、权限与二级菜单，学习成本过高。本产品用「零学习成本」的交互取代原生桌面，让长辈只面对几个大按钮。

**目标平台**：Android 手机（原生替换桌面的 Launcher 应用）。

## 2. 目标用户与核心场景

| 维度 | 说明 |
|---|---|
| 目标用户 | 从未接触过智能手机的长辈（60 岁以上） |
| 使用设备 | 子女提供的安卓手机，本产品设为默认桌面 |
| 核心场景 | ① 想看时间/天气 ② 想给子女打电话 ③ 想看家人照片 ④ 突发紧急情况求助 |
| 使用频率 | 高频日常使用，每次操作应「≤ 1 次点击」完成 |

## 3. 核心设计原则（体验底线）

这些是硬约束，任何功能都不得违反：

1. **一键直达**：所有操作控制在「点一下」以内，不设二级菜单。
2. **零学习成本**：无设置页、无账户、无权限弹窗；所有配置默认写死。
3. **看得清**：超大字体、超高对比度、大点击热区、防误触。
4. **稳定安全**：开机直达、响应快、无广告、不出错，禁止任何后台打扰。
5. **不依赖长辈操作**：联系人、紧急号码、相册内容由子女侧预置。

## 4. 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 语言/UI | Kotlin + Jetpack Compose | 现代 Android 原生，声明式 UI |
| 应用类型 | Launcher（桌面替换） + 常规 App 双形态 | 设为默认桌面，亦提供普通入口 |
| 系统能力 | 电话/短信 API、Launcher 清单 | 支撑拨号与 SOS |
| 数据 | 本地存储（联系人/相册预置） | 无需服务器、无账号 |

## 5. MVP 范围（整体方向）

**第一屏（桌面首页）**：大时钟 + 日期 + 天气，四个大图标（电话 / 家人 / 照片 / SOS），仅一屏、无滑动。

**MVP 只做 4 个核心功能**：

| 模块 | 功能定义 | 交互 |
|---|---|---|
| 电话 | 拨号 + 家人通讯录 | 一个「拨号」大按钮 → 头像+名字列表 → 点按即拨；**不提供实体拨号盘** |
| 家人 | 照片+名字列表 | 点击直接拨打或视频 |
| 照片 | 家人相册浏览 | 全屏大图轮播，点 / 滑切换 |
| SOS | 紧急求助 | 点两下确认 → 拨打预设号码 + 短信通知家人 |

## 6. 非目标（MVP 明确不做）

以下功能一律留到 MVP 之后的迭代，避免拖长周期：

- 视频通话（暂不接入账号体系）
- 消息 / 微信类即时通讯
- 吃药提醒、健康监测
- 账户体系、云同步
- 设置页与个性化配置

## 7. MVP 验收标准

- 开机（设为默认桌面后）直接进入大字桌面，无需任何点击。
- 桌面仅一屏，四入口均可「点一下」进入对应功能并完成操作。
- SOS 在两次确认后成功触发拨号与短信，且不会误触。
- 全应用无二级菜单、无设置页、无广告、无权限弹窗。
- 在低端安卓机上流畅运行，响应无卡顿。

## 8. 后续迭代方向（MVP 验证后）

视频通话 → 吃药/日程提醒 → 子女远程协助设置 → 极简消息。每一步都以真实长辈的接受度数据为准，不盲目堆功能。

## 9. 迭代功能（功能一 / 二 / 三，已实现）

> 在 MVP 四核心功能基础上，按实际落地迭代补充以下三个功能，延续「子女设置 + 长辈零操作」原则。版本：v0.1 增量，2026-09-22。

### 9.1 功能一：家人联系人可增删改（头像 / 手机号 / 微信备注 / 微信 ID）

**目标**：让子女能自行维护家人通讯录，而不是写死预设数据。

| 项 | 说明 |
|---|---|
| 入口 | 子女设置模式 → 管理家人 → 编辑联系人 |
| 能力 | 新增 / 删除 / 编辑联系人；可设置头像、手机号、微信备注、微信 ID（wxid） |
| 长辈侧 | 仍只点不编辑，电话页 / 家人页按最新名单展示 |
| 约束 | 微信备注全表唯一；微信 ID（wxid）全表唯一；wxid 留空表示该家人不进入家人页六宫格 |

### 9.2 功能二：家人一键微信视频

**目标**：长辈在家人页点一下「视频」按钮，自动在微信里向指定家人发起视频通话，无需切换微信。

**家人页形态（改版）**：六宫格（3 行 × 2 列，可滚动），只显示已配「微信 ID（wxid）」的家人；空格隐藏、整体居中；每格 = 方形大头像 + 姓名 + 微信备注小字 + 绿色「视频」按钮；**仅视频按钮可点**（防误触）。

| 项 | 说明 |
|---|---|
| 前置 | 联系人填写微信 ID（wxid）与微信备注；完成微信校准；开启无障碍 + 悬浮窗权限 |
| 交互 | 家人页六宫格出现「视频」按钮 → 点按自动发起微信视频；只显示已配 wxid 的家人 |
| 实现方式 | 沿用「无障碍坐标手势回放 + 剪贴板粘贴微信备注 + 微信顶部搜索路径」（路线一，7 步）；**深链方案已真机判死，不再替换**（见下方进展） |
| 定位 | 面向不会操作微信的长辈，用「一步点击」替代微信内的多步操作 |

> **功能二可靠性改造进展（2026-09）**
> - **深链（路线二 `weixin://dl/chat?username=wxid`）已在 Redmi Note 8 / 微信 8.0.76 真机逐一验证失效**：正例/负例/裸 `weixin://` 全部落到 `MMWebViewUI` 网页壳，从不进入原生聊天 `ChattingUI`，前后台、有无网络均无效。已拍板**放弃深链，采用已验证的路线一**（剪贴板粘贴备注 + 坐标手势回放 7 步）。
> - **时序由「纯固定延时」改为「事件驱动信号 + 延时兜底」**：利用微信投递的 `TYPE_WINDOW_STATE_CHANGED`（type=32，带 className+text）作步骤完成信号——等 `ChattingUI`（已进聊天）再点「+」、等 `dialog.a4`+文本「视频通话」（通话菜单）再点菜单「视频通话」；搜索段（放大镜/长按/粘贴/结果）无稳定类名信号，保留固定延时兜底。信号匹配为纯函数并带单测（6 用例全过）。
> - **校准向导多项改进**：悬浮窗权限 ON_RESUME 刷新（修授权后按钮卡死）；每步记录/验证/重录/完成/取消加 Toast 反馈；「是(通过)」阶段覆盖 bug 修复；开始校准自动把家人备注写入剪贴板（否则长按输入框无「粘贴」可呼出）；提示条降透明度、光标 48dp→28dp 并加中心十字准星（明确实际点击点=方框中心）。
> - **当前验证状态**：无障碍已开启；校准尚未完成（需子女在校准向导中完成 7 步坐标定位，当前正在解决第 1/2 步瞄准精度）；完成校准后回到家人页，「视频」按钮即显示。

### 9.3 功能三：六宫格桌面 + 导入第三方应用

**目标**：把长辈常用 App（如抖音）放进桌面，点击即可正常使用，避免在原生桌面找不到图标。

| 项 | 说明 |
|---|---|
| 桌面形态 | 四宫格扩展为六宫格（3 行 × 2 列），第三行两个格子用于第三方应用 |
| 导入 | 子女在设置模式勾选 / 白名单选择常用应用，上限 2 个 |
| 使用 | 长辈点击第三方应用格 → 正常打开该应用 |
| 卸载兜底 | 应用被卸载后，桌面自动隐藏对应图标，不报错 |
